# Texto Dissertativo-Argumentativo — Mini-curso Web Interativo

Apresentação web interativa criada em HTML, CSS e JavaScript puro. A versão atual foi ampliada para funcionar como um pequeno curso: além do conceito e da estrutura, inclui roteiro de construção, método para desenvolver argumentos, conectivos, exemplo prático, erros comuns, modelo rápido e quiz com 5 questões.

## Estrutura
- `index.html` — 11 etapas/slides do mini-curso.
- `style.css` — identidade visual, responsividade, cards e animações.
- `script.js` — navegação, conectivos, quiz, pontuação e reinício.

## Como executar
Abra `index.html` no navegador ou use Live Server no VS Code.

## Controles
- `→`, Espaço ou PageDown: próximo
- `←` ou PageUp: anterior
- `Home`: primeiro slide
- `End`: último slide
- Mouse: botões de navegação
